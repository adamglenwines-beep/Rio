# Textures

Free CC0 PBR texture sets (no attribution required), added by Adam for Phase A.
Converted from the original downloads for the browser:

- `*_color.jpg`: 2048 px, sRGB colour (Poly Haven "diff", ambientCG "Color").
- `*_normal.jpg`: 2048 px, **OpenGL** normal map (Three.js convention).
- `*_roughness.jpg`: 2048 px, greyscale.
- `*_height.jpg`: 1024 px, greyscale displacement/height (useful for height-blending and parallax).
- `*_ao.jpg`: 2048 px ambient occlusion, ambientCG sets only (Poly Haven sets have none; bake or skip).

Originals were 4K; downsized here. Ask Adam if a 4K version is ever needed.

Note: Liguria is dry and sunny, so prefer the less mossy roof sets.
